# IndusMove Logistics – Industrial Transportation Service

A web-based business app for a fictional industrial transport company (ITBT live class exercise).

**Live site:** https://shreya-3426.github.io/Shreya-BusinessApp/

## Business problem
Factories and plants lose money when heavy cargo arrives late and they cannot see where it is. IndusMove gives customers shipment tracking and gives managers a one-screen view of fleet performance.

## Sections
Home, About Business, Services (with prices), Manager Dashboard (6 KPIs + chart), Contact / Enquiry.

## Business feature
**Track shipment** – enter an ID (TRK1021, TRK1023 or TRK1025) to see status, location, ETA, vehicle, driver and contact.

## Hyperlinks and their purpose
- Nav links and "Get Started": move users to the section they need
- Services → Contact: request a quote
- Dashboard → Track a shipment: drill from fleet KPIs to one shipment
- Google Maps: find the head office
- Email and "Send enquiry": start a quote request
- Ministry of Road Transport: rules and permits for road freight
- LinkedIn: company profile

## Publish on GitHub Pages
1. Create a repository named `StudentName-BusinessApp` and upload all files (keep the `images` folder).
2. Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save.
3. After about a minute, open the link shown and submit it.

## 2-minute presentation
1. **Business:** IndusMove, an industrial road-transport company for heavy and bulk cargo.
2. **Problem:** Plants cannot see where cargo is, so delays stop production.
3. **Customer:** Steel, cement, chemical, auto-parts and engineering plants, and EPC contractors.
4. **App:** Presents services and prices, tracks a shipment by ID, and takes quote enquiries.
5. **Dashboard:** Vehicles available, trips completed, shipments in transit, delayed shipments, on-time delivery %, fuel efficiency, and weekly on-time vs delayed trips.

## Enquiry form setup
1. In `script.js` set `OWNER_EMAIL` and `WHATSAPP_NUMBER` to your own details.
2. Publish on GitHub Pages, open the live link and send one test enquiry.
3. FormSubmit emails you an activation link the first time. Click it (check Spam), then send another test.
